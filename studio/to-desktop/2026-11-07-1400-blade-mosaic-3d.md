# Blade Mosaic is now 3D

## What and why
The user asked for 3D. The mosaics are now lit 3D cubes standing on a floor, with shadows. Each blade is a 3D metal model that grinds the faces of the blocks, broken pieces tumble away as small cubes, and the camera drifts with the blade and shakes on crashes. The rules, physics and balance are unchanged; only the drawing is new.

## Details
- Uses three.js r128 from cdnjs. Without internet or WebGL, the game falls back to the 2D view and the 3D button is hidden.
- The HUD button (or the V key) switches between 3D and 2D, and the choice is saved. 2D is lighter if an older iPad struggles.
- Mouse aiming and iPad drag both work through the 3D camera.
- Tested in headless Chromium with software WebGL: no errors. Checked levels 1, 3, 4, 10 and 11 with several blades, a falling cap, a touch drag on an iPad-sized screen, the 3D/2D switch, and the offline fallback.

## Done when
Try it on a real classroom iPad to confirm 3D runs smoothly. If it does not, 2D can be made the default there.
