# Prompt to continue Whisker Dash in a new session

Copy everything in the box into a new Claude session (attach the "whisker dash" project, or attach `index.html` and the `.md` files from `whisker-dash/`).

```
Let's keep developing my game Whisker Dash, a single-file pixel-art cat platformer (HTML canvas, no libraries).

Where things are:
- Live game: my claude.ai artifact "Whisker Dash" — https://claude.ai/artifact/C66TYqxe54unZ12gz2VepF
- Docs and a copy of the game: the "whisker dash" project (PLAN.md, GAME-FILE.md, NEXT-STEPS.md, index.html),
  and my private repo samueldee-oss/k12-sd-fun, folder whisker-dash/.

Before changing anything:
1. Read PLAN.md, GAME-FILE.md and NEXT-STEPS.md.
2. Read the LIVE artifact first and build on that version — other sessions may have changed it since the docs were written.
3. Don't retype the file. Make small find-and-replace patches, then test in a real browser (Playwright):
   load every level with no errors, and try the new feature yourself with screenshots.

Rules:
- No copyrighted characters, songs or logos. The platypus stays light green with a blue frog "Pip" on its head and no hat.
  Queen Purrcilla is an original cat, not a real person.
- No student personal details in anything committed; the repo is on GitHub.
- Don't spoil secrets I ask you to hide (for example, don't tell me where the secret lobby is).
- Only commit or push when I ask.

After every update:
1. Publish the new version to the same artifact (check you're replacing the live version).
2. Send me a fresh standalone WhiskerDash.html for my class. That copy must NOT load Google fonts
   (remove the fonts.googleapis.com link) and must have OWNER_RESTORE set to 0. See "Making the class copy" in GAME-FILE.md.
3. Update PLAN.md (plan iterations), GAME-FILE.md (version table) and NEXT-STEPS.md, and save them to the project and the repo folder.

My testers are kids in one school district with Microsoft school accounts; I don't want a public website.

First thing: tell me in one line what version you found and that you're ready. Then wait for my next idea.
```
