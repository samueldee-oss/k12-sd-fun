# Whisker Dash

A pixel-art cat platformer in one file: 50 worlds, 245 levels, 80 skins, a Hotel Lobby hub with talking characters,
rides and mini-games, 1 or 2 players, keyboard or touch, 5 save slots. Open `index.html` in a browser, or use the Whisker Dash card on the dashboard.

| File | What it is |
|---|---|
| [`index.html`](index.html) | The whole game (HTML, CSS and JavaScript in one file). |
| [`PLAN.md`](PLAN.md) | The design plan: rules, every world and level, characters, the lobby, mechanics, and how the plan grew round by round. |
| [`GAME-FILE.md`](GAME-FILE.md) | How `index.html` is organized, how it changed version by version, and how to recreate or continue it. |
| [`tests/`](tests/README.md) | Scripts that check the game automatically. |
| [`NEXT-STEPS.md`](NEXT-STEPS.md) | Short handover note for the next session. |
