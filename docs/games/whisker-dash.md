# Whisker Dash

- **Genre:** cat-themed arcade runner (largest and most developed project)
- **File:** `whisker-dash/index.html` (~370 KB, single file; `WhiskerDash.html` is the same release)
- **Live link:** `https://samueldee-oss.github.io/k12-sd-fun/whisker-dash/`
- **Save keys:** `whiskerdash_slot`, `whiskerdash_sfx` (see the file for the full list)

## Where the real documentation is

- `whisker-dash/PLAN.md` — design plan
- `whisker-dash/GAME-FILE.md` — structure of the game file
- `whisker-dash/NEXT-STEPS.md` — roadmap and open items
- `whisker-dash/README.md` — overview
- `whisker-dash/tests/` — tests
- `docs/provenance/` — transcripts and code snapshots from the earlier build sessions

## Notes for this archive
- The public copy ships with `OWNER_RESTORE=0` (an owner-only restore hook is switched off).
- Slot-based saves and an SFX preference are stored in localStorage.
- To reproduce: follow `GAME-FILE.md`; for a regenerative rebuild use [REPRODUCING.md](REPRODUCING.md) and the plan documents as the spec.
